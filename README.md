# my-dash-next-h

Dashboard Next.js (App Router) + Redux Toolkit.

## Requisitos

- Node.js `>=20.9.0`
- npm (el lockfile es `package-lock.json`)

## Setup

```bash
npm install
npm run dev
```

App en [http://localhost:3000](http://localhost:3000).

## Otros comandos

```bash
npm run build   # producción
npm start       # sirve el build
npm run lint
```
